# Frontend Mentor - Recipe Page

This is my solution to the Recipe Page challenge from Frontend Mentor.

## Overview

I built a simple and responsive recipe page using HTML and CSS.

The page includes:

- Recipe image
- Recipe description
- Preparation time
- Ingredients
- Cooking instructions
- Nutrition information

## Built With

- HTML5
- CSS3
- Semantic HTML
- CSS Grid
- Responsive Design

## What I Learned

Through this project, I improved my understanding of semantic HTML,
responsive layouts, ordered lists, unordered lists, and HTML tables.

I also learned how to structure a webpage using elements such as
`header`, `main`, `section`, `ol`, `ul`, and `table`.
